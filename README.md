# FuzzyLogics
## Сборка проекта
Системные требования: ОС Windows 10 и выше (x64).
Предустановленное ПО:
1.	Microsoft Visual Studio 2022 или новее с рабочей нагрузкой «Разработка классических приложений на C++»;
2.	Git для клонирования репозитория;
3.	Vcpkg – менеджер пакетов для C++:
   3.1 Склонируйте репозиторий https://github.com/microsoft/vcpkg;
   3.2 Перейдите в директорию vcpkg и запустите bootstrap-vcpkg.bat;  
   3.3 Создайте переменную среды VCPKG_ROOT, указывающую на директорию, содержащую vcpkg.exe.
Сборка:
1.	Клонировать этот репозиторий;
2.	Открыть папку в Visual Studio (File -> Open -> Folder);
3.	Дождаться, пока Visual Studio выполнит конфигурацию CMake (зависимости из vcpkg.json установятся автоматически). Если конфигурация не запустилась, выберите «Project -> Configure Cache».
4.	Собрать проект: «Сборка» -> «Собрать всё» (Build -> Build All)
5.	fuzzy_cli.exe и MyFuzzyApp.exe будут лежать в директории out\build\x64-Debug\bin.

## Порядок использования
MyFuzzyApp.exe – точка входа в приложение, запускать его нужно первым. CLI (fuzzy_cli.exe) можно запустить по кнопке из GUI или отдельно (если GUI уже запущен). 
Графический интерфейс (GUI):
1.	График: отображает нечёткие величины. Для навигации используются мышь: колесо - масштабирование, зажатая левая кнопка - перетаскивание.
2.	Панель управления:
   2.1 Generate – сгенерировать 50 пуассоновских величин (λ от 10 до 20);
   2.2 Command prompt – запустить консольный клиент;
   2.3 Clear – очистить сессию;
   2.4 Minimize – свернуть окно;
   2.5 Exit – завершить работу (влечет незамедлительное закрытие cli).
3.	Лог: отображает список величин (индекс, цвет, центроид, размер). Подходящие под фильтр величины выделяются цветом, остальные – серым.
4.	Фильтры: позволяют отобрать величины по длине интервала, центроиду и ширине α-среза при заданном α. Фильтр не удаляет данные, а лишь визуально выделяет подходящие.
Консольный клиент (CLI):
После запуска введите help, чтобы увидеть список команд. Основные команды:
1.	generate <n> <lmin> <lmax> <M> - сгенерировать n величин с λ в диапазоне [lmin, lmax];
2.	add, sub, mul, div <i> <j> - арифметические операции над величинами i и j;
3.	compare <i> <j> - сравнить центроиды;
4.	cluster <c> - выполнить кластеризацию FCM на c кластеров;
5.	list, print <i>, centroid <i> - вывести информацию о величинах;
6.	save <path>, load <path>, log <path> - работа с файлами;
7.	clear, remove <i> - управление сессией;
8.	exit - выход из CLI.
GUI и CLI работают с одной сессией через разделяемую память. Изменения, сделанные в CLI (например, add или generate), мгновенно отображаются в GUI. При закрытии GUI консольный клиент завершается автоматически.
